# Codex Budget

**Выполняйте полезные задачи, бережнее расходуя лимит Codex.**

[English](README.en.md) · [Инструкция скилла](skills/codex-budget/SKILL.md) · [MIT](LICENSE)

Небольшой локальный скилл для работы с подписочным лимитом: выбор разумного подхода, меньше повторного исследования и лишних попыток, необходимые проверки и аккуратные замеры расхода.

**Статус: экспериментальная версия 0.1.0. Экономия ещё не подтверждена сравнительными замерами.**

## Что он делает

- Помогает выполнять задачу без ненужного расширения объёма.
- Напоминает использовать готовые результаты и локальные инструменты для механической обработки.
- При запросе советует настройки по сложности задачи и актуальной документации.
- При наличии инструмента статистики помогает сравнить расход квоты до и после работы.
- Учитывает округление, сброс окна, задержки учёта и активность других чатов.

Скилл не увеличивает квоту, не меняет модель сам по себе и не обеспечивает жёсткий предел расхода. Он не переносит работу на платный API и не подключает телеметрию. Создание журналов измерений выполняется только по запросу, вне установленного скилла.

## Установка

В Codex с доступным `skill-installer`:

```text
$skill-installer установи скилл из https://github.com/Skynetuz/codex-budget/tree/main/skills/codex-budget
```

Либо скачайте репозиторий и скопируйте **только папку `skills/codex-budget`** в каталог локальных навыков вашей установки. В окружениях с `$CODEX_HOME/skills` используйте его, а при стандартной конфигурации — `~/.codex/skills`. Текущая документация также описывает пользовательский каталог `~/.agents/skills` и проектный `.agents/skills`: используйте путь, который поддерживает ваша версия. Не устанавливайте один и тот же скилл сразу в несколько сканируемых каталогов.

Проверьте появление `Codex Budget` в списке навыков. Если он не появился, перезапустите Codex и сверьтесь с [документацией установки](https://learn.chatgpt.com/docs/build-skills).

GitHub-публикация не означает включение в официальный каталог OpenAI. Ключи и внешние сервисы для работы самого скилла не нужны.

## Примеры

```text
$codex-budget Исправь ошибку в импорте CSV. Сохрани текущую модель,
не расширяй задачу и выполни необходимые проверки.
```

```text
$codex-budget Посоветуй экономные настройки для небольших правок сайта.
Пока ничего не меняй в настройках.
```

```text
$codex-budget Замерь изменение доступной квоты за эту задачу.
Если статистика недоступна или окно сбросилось, укажи это.
```

Инструкции написаны на английском для переносимости; использовать скилл можно на русском. Автоматический выбор разрешён для запросов об экономии квоты, но скилл не навязывается всем задачам.

## Как проверить пользу

Сравнивайте несколько похожих задач с одинаковыми требованиями к результату. При проверке самого рабочего процесса сохраняйте модель, effort и скорость. При проверке другой модели фиксируйте это как отдельное изменение.

Измеряйте процентные пункты расхода каждого окна отдельно, учитывая параллельную активность. Проверяйте качество и повторные исправления. Высокая доля кэшированных токенов сама по себе не доказывает экономию подписочной квоты.

Подробности: [методика замеров](skills/codex-budget/references/measurement.md).
