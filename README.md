## Зачем это нужно

Несколько коротких сообщений могут запустить много работы: поиск по проекту, чтение файлов, попытки исправления, проверки и повторный анализ. **Codex Budget помогает организовать этот процесс**, сохраняя требования к результату.

Это небольшой локальный навык с открытым исходным кодом. Он не увеличивает лимит и не обещает фиксированную экономию. Версия **0.2.0** включает утилиту сравнения замеров и воспроизводимые тесты.

| В обычной задаче бывает | Что предлагает скилл |
|---|---|
| Повторное чтение уже изученных файлов | Использовать актуальные результаты и читать изменения |
| Большие логи ради одной ошибки | Отфильтровать данные локально и изучить нужный фрагмент |
| Несколько одинаковых неудачных попыток | Менять следующий шаг на основании ошибки |
| Попутные улучшения за пределами задачи | Довести согласованный результат до готовности |
| «Процент не изменился — значит бесплатно» | Учесть округление и задержки учёта |

## Быстрый старт

В Codex с доступным `skill-installer`:

```text
$skill-installer установи скилл из https://github.com/Skynetuz/codex-budget/tree/main/skills/codex-budget
```

Затем:

```text
$codex-budget Исправь ошибку импорта CSV. Сохрани текущую модель,
не расширяй задачу и выполни необходимые проверки.
```

Для использования основных инструкций **Python, API-ключи и дополнительные сервисы не нужны**. Python 3.10+ нужен только для необязательной утилиты замеров.

<details>
<summary><strong>Ручная установка и обновление</strong></summary>

Скопируйте папку `skills/codex-budget` в каталог навыков, поддерживаемый вашей установкой Codex. В окружениях с `$CODEX_HOME/skills` используйте этот путь, обычно `~/.codex/skills`. Текущая документация также описывает `~/.agents/skills` для пользовательской установки и `.agents/skills` для проекта.

Используйте один поддерживаемый путь, чтобы не получить дубликаты. При обновлении сохраните собственные изменения, если они есть, и замените файлы этого скилла новой версией.

Проверьте появление `Codex Budget` в списке навыков. Если он не появился, перезапустите Codex и сверьтесь с [документацией](https://learn.chatgpt.com/docs/build-skills).

Публикация на GitHub не означает включение в официальный каталог OpenAI.

## Три способа применения

**Выполнить задачу экономнее**

```text
$codex-budget Добавь валидацию формы и проверь её.
Текущую модель и настройки оставь.
```

**Подобрать настройки**

```text
$codex-budget Посоветуй настройки для небольших правок сайта.
Объясни компромиссы; пока ничего не переключай.
```

**Измерить наблюдаемый расход**

```text
$codex-budget Сними доступные показания квоты до и после этой задачи.
Отдели пятичасовое окно от недельного и укажи ограничения замера.
```

Скилл может выбираться автоматически для запросов об экономии квоты. Он не включается по умолчанию для любой работы.

## Что уже проверено

**28 локальных автоматических тестов пройдены** на утилите сравнения показаний: обычный прирост, остаток квоты, сброс окна, пропуски, некорректные данные, CLI и отсутствие записи во входные файлы.

Опубликован [отчёт о практическом запуске и показаниях квоты](docs/test-report.md). Эти результаты проверяют корректность утилиты и фиксируют наблюдения. Они **не доказывают**, что скилл экономит определённый процент.

Бейдж тестов — статический итог локального запуска, не индикатор GitHub Actions.

## Как это связано со статьёй о кэшировании

Обсуждение началось со [статьи на Хабре о KV-кэше](https://habr.com/ru/articles/978498/). Кэш позволяет повторно использовать некоторые серверные вычисления. Это полезная основа для понимания, но скидка на входные токены API не переводится напрямую в проценты подписочного лимита.

В [подробном руководстве](docs/guide.ru.md) разобраны механизм кэша, отличие от квоты Codex, практические примеры и ограничения скилла.

## Границы возможностей

| Может помочь | Не обеспечивает |
|---|---|
| Уменьшить повторную работу и лишний контекст | Увеличение или обход лимита |
| Рекомендовать настройки под задачу | Скрытое переключение модели |
| Сравнить доступные показания | Точный счёт за одну задачу |
| Сохранить необходимые проверки | Гарантию экономии без эксперимента |

Никакой телеметрии и платных API-вызовов в комплекте нет. Утилита работает только с переданными локальными JSON-файлами. Журналы приватны по умолчанию; публичный отчёт создаётся только по явному запросу пользователя.
